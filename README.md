# 福建中考志愿助手
福建中考的折分、总评、体育算分与志愿落位工具 —— 一个 `index.html` + 一个 `data.js`，双击即用，不安装、不联网、不上传。

---

## 功能

1. **折分** —— 9 门课卷面分按福建 800 分制折算成投档总分（语数英原始分；物理 90%、化学 60%、道法 50%、历史 50%、地理 30%、生物 30%；体育 40 分）。
2. **体育算分** —— 按项目填实测成绩（如 1000 米跑 `4:20`），查《福建省初中毕业升学体育与健康考试实施方案》原表给百分制，再乘权重折算。
3. **总评** —— 总分、得分率、强科弱科、离各条投档线还差多少，附一句结论。
4. **提升计划** —— 非「正式中考」场次自动生成：按「卷面可提分 × 该科权重」排序，指出先补哪几科、每科怎么补、目标分多少。
5. **预估排名** —— 用 2026 年官方分数段锚点插值出全市位次；勾选定向生资格后，可填校内名次/年级人数/定向名额，判断「定向·名额内 / 外」。
6. **志愿** —— 从 2026 年真实录取线里筛出冲（差 0–25 分）/ 稳（高 0–20 分）/ 保（高 20 分以上）三档，出 1、2、3 志愿表。
7. **打印成绩单** —— 重排一张 A4 单页（不是截屏），含折算明细、体育明细、定位与志愿建议，可直接打印或存 PDF。

## 环境要求

- 任意近两年的现代浏览器（Safari / Chrome / Edge / Firefox），**不需要** Node、Python、构建工具或网络。
- 成绩与选择保存在浏览器 `localStorage`，换浏览器或清缓存会丢，重要数据请先「打印成绩单」存 PDF。

## 构建与运行

**没有构建步骤，没有依赖，没有 npm install。**

```bash
# 方式一：直接双击（macOS Finder 里双击 index.html 即可）

# 方式二：起一个本地静态服务器再访问
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

> `index.html` 通过 `<script src="data.js">` 读取数据，所以 `data.js` 必须和 `index.html` 放在同一层目录。移动文件时两个一起移动。

## 已知边界

- **不是录取预测。** 只按分数落位，没算等级门槛（省一级达标校对 9 科等级有要求）、没算照顾分、没算同分排序规则。
- **志愿模式因市而异**：福州平行志愿（1A/1B + 定向生）、厦门平行志愿、泉州梯度志愿（第一志愿最关键）。正式填报以本市当年细则为准。
- **定向生只按福州规则估算**：必须填第一志愿 1A 才有效，录取在统招第一志愿最低投档线下 45 分内、以初中校为单位按校内排名取。软件用 20 分（区间中位）做默认降分，可拉到 0–45；不区分具体初中校的名额，实际落点可能差很多。其他市不代算。
- **三明、龙岩、平潭未录入学校线**；宁德（除福鼎）、漳州（除头部）也只覆盖少数学校。
- **全市排名是插值估算，不是一分一段表**：福州 4 个锚点、厦门 27 个锚点、泉州只有 3 个锚点（误差更大），其余市不估算并会说明原因。结果取整到百位。
- **2027 预测线是参数化估算**（年际漂移 +4 分/年、新教材首年 +6 分，默认合计 +10，可自行拉），不是官方数据。
- 体育免考、缓考等特殊情况不在计算范围内。
- 分数线为 2026 年数据，只作定位参考。

## 数据与素材来源

- **各市 2026 年普通高中录取线 / 批次控制线**：各市教育局、市中招办公布的当年录取公告，人工录入 `data.js`。
- **分数段（一分一段）锚点**：福州六区、厦门全市、泉州全市 2026 年公开发布的分数段统计。
- **体育评分表**：《福建省初中毕业升学体育与健康考试实施方案（试行）》（闽教体〔2020〕18 号）原表，按 26 档百分制换算。
- **2027 年抽选考项目**：各市摇号结果公示。
- 本项目与上述机构无关联，数据可能有录入误差，以官方发布为准。
